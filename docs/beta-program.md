# Cortex AI - Private Beta Program Guidelines

**Author:** Beta Program Coordinator & Growth Analyst  
**Version:** v1.0  
**Target:** Selected pioneers, developers, and founders  

---

## 1. Beta Program Vision & Goals

Welcome to the **Cortex AI Private Beta**! 
Our primary focus during this phase is to collect real-world user feedback, audit AI token costs, analyze feature adoption rates, and harden our database RLS security boundaries before opening public registrations.

---

## 2. Beta Access Codes Allocation
- To register, you must be whitelisted and receive a unique **Beta Access Code** (e.g. `CORTEX_BETA_2026`).
- Each code is restricted to a specific email address and is valid for a single, one-time consumption during register setups.

---

## 3. Growth & Usage Telemetry Audit
We monitor key product performance indexes (KPIs) through our central telemetry pipelines:
- **DAU (Daily Active Users):** Counts unique user sessions.
- **AI Request Frequency:** Traces total AI requests.
- **Response Ratings:** Analyzes Thumbs up/down rates on AI completions to feed our reinforcement learning pipelines.
